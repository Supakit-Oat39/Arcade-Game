# Arcade Game

เว็บรวมเกมแบบ Mobile-first ไม่ต้อง Login ไม่มี Backend
หน้าแรกเป็นเมนูเลือกเกม ตอนนี้มี 1 เกมคือ **ไพ่ปาร์ตี้**

## โครงสร้างไฟล์

```
Arcade Game/
├── index.html                  หน้าแรก (เลือกเกม)
├── css/style.css               ธีมที่ใช้ร่วมกันทุกหน้า (โต๊ะผ้าสักหลาดเขียว / ทอง)
├── games/
│   └── party-cards/
│       ├── index.html          หน้าเกม: เลือกจำนวนคน → โต๊ะเปิดไพ่
│       ├── style.css           หน้าไพ่ป๊อก, แอนิเมชันพลิกไพ่, layout มือถือ
│       └── game.js             สำรับ 52 ใบ, สับไพ่, ลำดับตาผู้เล่น, หน้าที่ของไพ่ (ROLES)
└── scripts/serve.mjs           เซิร์ฟเวอร์ทดสอบบนเครื่อง (ไม่ต้องติดตั้งอะไร)
```

ไม่มีขั้นตอน build — เป็นไฟล์ static ล้วน นำไปวางบน static hosting ได้ทันที (ทุกลิงก์เป็น relative path ใช้กับ GitHub Pages แบบ `/<repo>/` ได้)

## เปิดใช้งานบนเครื่อง

```bash
cd "Arcade Game"
npm start            # เปิด http://localhost:5173
```

> ดับเบิลคลิก `index.html` ก็เปิดได้เหมือนกัน (ไม่ได้ใช้ JavaScript modules)
> ถ้าไม่มี Node ใช้ `python3 -m http.server 5173` แทนได้
>
> ทดสอบบนมือถือ: ให้มือถืออยู่ Wi-Fi เดียวกัน แล้วเปิด `http://<IP ของคอมพิวเตอร์>:5173`

## Deploy (GitHub Pages)

1. สร้าง repo ใหม่บน GitHub แล้ว push branch `main`
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. รอประมาณ 1 นาที เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

## เกม: ไพ่ปาร์ตี้

1. เลือกจำนวนผู้เล่น (เริ่มต้น 2 คน, สูงสุด 20 คน) แล้วกด "เริ่มเกม"
2. ระบบบอกว่าถึงตาผู้เล่นคนไหน คนนั้นกด "เปิดไพ่" (หรือ Spacebar) ทีละใบ
3. ไพ่พลิกขึ้นพร้อมหน้าที่ของใบนั้น แล้ววนไปคนถัดไป
4. ไพ่หมด 52 ใบ → "สับไพ่ เล่นอีกรอบ" / ปุ่ม "สับใหม่" มุมขวาบนเริ่มใหม่ได้ทุกเมื่อ

| ไพ่ | ชื่อ | ทำอะไร |
|---|---|---|
| A | จิบ 1 จิบ | คนจับได้ดื่ม 1 จิบ |
| 2 | จิบ 2 จิบ | คนจับได้ดื่ม 2 จิบ |
| 3 | จิบ 3 จิบ | คนจับได้ดื่ม 3 จิบ |
| 4 | หมดแก้ว | คนจับได้ดื่มหมดแก้ว |
| 5 | บัดดี้ | เลือกเพื่อน 1 คนเป็นบัดดี้ ใครโดนดื่ม อีกคนต้องดื่มด้วย |
| 6 | หมวดหมู่ | ตั้งหมวด เช่น ยี่ห้อรถ ชื่อผลไม้ แล้วไล่ตอบทีละคน ใครตอบช้าหรือตอบซ้ำ ดื่ม |
| 7 | เซเว่นอัพ | นับเลขต่อกันทีละคน เลขที่มี 7 หรือหาร 7 ลงตัว ให้พูด "เซเว่นอัพ" แทน ใครพลาด ดื่ม |
| 8 | เข้าห้องน้ำ | ได้สิทธิ์เข้าห้องน้ำ 1 ครั้ง เก็บไว้ใช้ทีหลังได้ คนที่ไม่มีสิทธิ์ห้ามลุกไปห้องน้ำ |
| 9 | ซ้ายดื่ม | คนที่นั่งทางซ้ายมือของคนจับได้ ดื่ม |
| 10 | ขวาดื่ม | คนที่นั่งทางขวามือของคนจับได้ ดื่ม |
| J | ห้ามพูด | คนจับได้ห้ามพูด จนกว่าจะมีคนจับได้ J ใบต่อไป เผลอพูด ดื่ม |
| Q | ห้ามคุยด้วย | ทุกคนห้ามพูดกับคนจับได้ จนกว่าจะมีคนจับได้ Q ใบต่อไป ใครเผลอคุยด้วย ดื่ม |
| K | ตั้งเงื่อนไข | ตั้งคำสั่งให้คนที่จับได้ K ใบต่อไปต้องทำ เช่น ดื่มหมดแก้ว |

แก้หน้าที่ไพ่ได้ที่ `ROLES` ใน `games/party-cards/game.js`
ปรับจำนวนผู้เล่นได้ที่ `playerCount` / `MIN_PLAYERS` / `MAX_PLAYERS` ในไฟล์เดียวกัน

## เพิ่มเกมใหม่

1. สร้างโฟลเดอร์ `games/<ชื่อเกม>/` พร้อม `index.html` (ลิงก์ `../../css/style.css` เพื่อใช้ธีมเดียวกัน)
2. แก้การ์ด "เกมถัดไป" ใน `index.html` หน้าแรกให้เป็น `<a class="game-tile" href="games/<ชื่อเกม>/index.html">`
